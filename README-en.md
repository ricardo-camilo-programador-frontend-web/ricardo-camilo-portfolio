# Ricardo Camilo Portfolio

A modern portfolio project built with Next.js 15, React 19, and TailwindCSS 4.

## 🚀 Features
- **Next.js 15 (App Router)**: Optimized performance and SEO.
- **TailwindCSS 4**: Modern and fast styling.
- **Internationalization (i18n)**: PT-BR and EN-US support.
- **GitHub API Integration**: Dynamic project fetching.
- **PWA**: Installable and works offline.
- **Accessibility**: WCAG 2.1 AA compliant.

## 🛠 Tech Stack
- **Framework**: Next.js 15
- **Library**: React 19
- **Style**: TailwindCSS 4
- **Language**: TypeScript
- **Tests**: Vitest
- **Validation**: Biome (Lint/Format)

## 📦 Installation
```bash
pnpm install
```

## ⌨️ Commands
- `pnpm dev`: Start development server.
- `pnpm build`: Create production build.
- `pnpm lint`: Run linter.
- `pnpm type-check`: Verify TS types.
- `pnpm test`: Run test suite.
