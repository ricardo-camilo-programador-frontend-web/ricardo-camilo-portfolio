# Portfolio Ricardo Camilo

Projeto de portfólio moderno construído com Next.js 15, React 19 e TailwindCSS 4.

## 🚀 Features
- **Next.js 15 (App Router)**: Performance e SEO otimizados.
- **TailwindCSS 4**: Estilização moderna e rápida.
- **Internacionalização (i18n)**: Suporte para PT-BR e EN-US.
- **GitHub API Integration**: Projetos buscados dinamicamente.
- **PWA**: Instalável e funciona offline.
- **Acessibilidade**: Seguindo WCAG 2.1 AA.

## 🛠 Tech Stack
- **Framework**: Next.js 15
- **Library**: React 19
- **Style**: TailwindCSS 4
- **Language**: TypeScript
- **Tests**: Vitest
- **Validation**: Biome (Lint/Format)

## 📦 Instalação
```bash
pnpm install
```

## ⌨️ Comandos
- `pnpm dev`: Inicia o ambiente de desenvolvimento.
- `pnpm build`: Gera a build de produção.
- `pnpm lint`: Executa o linter.
- `pnpm type-check`: Verifica tipos TS.
- `pnpm test`: Roda a suite de testes.
